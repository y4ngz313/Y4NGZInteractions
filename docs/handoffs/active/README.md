# Active handoffs

Last updated: 2026-08-05

This directory contains only work that is actively paused on an open issue. An active handoff must
record:

- the canonical issue and feature parent, when one exists;
- the current branch and draft pull request, when one exists;
- the last verified state and the evidence supporting it; and
- unresolved questions requiring an answer.

Describe state, not a prescribed next mechanism. When work resumes or the issue resolves, consume
the handoff and move it to `../archive/YYYY-MM/`.

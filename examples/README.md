# Public Examples

Last updated: 2026-08-08

This repository-only workspace proves that both presentation paths can be authored and consumed without private scripts or extracted game assets.

- UnityProject is pinned to Unity 2022.3.62f1 and generates original primitive proxy/viewmodel assets, controllers, clips, schema-2 manifests, and bundles.
- SampleConsumer is a buildable BepInEx plugin with legacy-input hotkeys and a minimal consumer-owned named network message.

GeneratedBundles is intentionally not part of the Thunderstore package. Generate it locally from the Unity project.
